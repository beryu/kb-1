# kb-1 単4電池テンティングバー — 試作 Rev E

単4電池1本、GB-BH-4X1-WP、既製の昇圧モジュールを収める磁石着脱式バー。
専用電源PCBを廃止し、着脱できるPLA製部品トレーと絶縁配線に変更した。
今回作った `pcb/battery-tenting-bar/` のKiCadプロジェクト、製造データ、生成スクリプトは削除済み。
既製の昇圧モジュール自体には小型の実装済み基板がある。

別リポジトリ `kb-1/kb.FCStd` の底ケース・上ケース・磁石穴・USB-C端子位置を読み取り、
左右別のモデルを生成している。元のキーボードケースは変更していない。

- 本体、部品トレー、昇圧モジュール押さえ、磁石用内蓋、脱落防止カバー、背面スライドふたの6点構成。
- GB-BH-4X1-WPの開口を背面へ向けて固定。磁石カバーのねじを外さず、電池だけ交換する。
- ホルダー、スイッチ、PTC、ダイオードに位置決め枠と結束バンド用穴を追加。
- トレー裏面に配線溝とホルダー端子の貫通穴を追加。先にはんだ付け・絶縁してから部品を固定する。
- 全8か所をM2ねじでPLAへ直接固定。インサート6個と六角ナット2個を廃止。
  トレーはねじ2本で着脱し、昇圧モジュールは別体押さえで保持。
- 内蓋の長い差し込み棒4本を削除。短い側面の位置合わせ用舌は残している。
- 左右のUSB-Cポート側へ固定ケーブルの出口と外皮を保持する台座を追加。
- Ø22mmの指掛かりと、磁石を閉じ込めるねじ式カバーを維持。

## 生成物

[FreeCADモデル](generated/battery-tenting-bar/kb1-aaa-tenting-bars.FCStd)

`generated/battery-tenting-bar/` に左右それぞれの `housing`、`tray`、`module-cage`、`lid`、`cover` の
STLとSTEP、左右の `battery-door` のSTLとSTEPを保存している。STLは印刷台に載せる向き・高さへ変換済み。
磁石穴の試し刷り用 `magnet-fit-coupon` と `magnet-fit-cover` も含む。
部品・工具・配線は[部品表](BATTERY-TENTING-BAR-PARTS.md)を参照。

磁石はカバーを外し、各穴でケースと引き合う向きを確認して指で入れる。
磁石の上面全体に樹脂があり、上に引かれてもカバーに当たって外へ抜けない。
計算上、引き寄せられた磁石とケース側磁石の間に約0.98mmの樹脂が入る。
吸着力・横滑り・薄肉の強度は印刷品で評価する。磁石穴クーポンは寸法確認用で、
ねじ締結と保持力の確認は本体でも必要。

## USB-C給電の取り付け方

バーにはUSB-Cオス付きの短い固定ケーブルを組み込み、キーボードの既存USB-C端子へ挿す。
本体の出口と台座でケーブル外皮を結束バンド固定するため、別の給電ケーブルを持ち運ばずに使える構成。
硬いプラグをバーに直結する台座は設けず、柔軟なケーブルで取り付け誤差を逃がす。

FreeCADには `…FixedUSBCPlug` と `…FixedCable` の参照形状を追加した。
プラグ樹脂部分は12 × 12 × 6mm、ケーブル外径3mmの仮定で、メーカーの実測STEPではない。
左右の出口をそれぞれ近いポート側へ振り分け、ケース外を通るケーブル経路を作成した。
モデル上の外側経路長は左右とも約115mm。内部の接続分と組み立て余長を加えてから現物で切断長を決める。
曲げ形状は干渉確認用で、実ケーブルの最小曲げ半径を保証しない。

キーボード端子の位置も元モデルの概略箱による。
バー座標の端子中心は左(99.74, −6.21, 41.14)、右(0.26, −6.21, 41.14)mm。
プラグの挿入・抜去空間、端子の実高さ、線径、CC抵抗を現物で確認する。

## 組み立て

1. 電池を装着したGB-BH-4X1-WPの外形・高さ・接点間隔、モジュールのはんだ込み高さ、
   スイッチ・PTC・ケーブル外径を測る。[ホルダーの販売元仕様](https://www.marutsu.co.jp/pc/i/595611/)では
   単4×1本・底面ピン式を確認できるが、ここで使った精密寸法と抜き差し動作は現物で確認する。
2. トレーと本体・スライドふたを試し刷りし、ホルダーを横向きに保持できること、
   レールの滑り、爪の解除・保持、電池の着脱を確認する。磁石クーポンで磁石の適合も確認する。
   本体・トレー・押さえは底を下に印刷する。内蓋・上カバー・背面ふたはSTLの向きで印刷する。
   背面ふたは内面を印刷台に置く向きへ変換済みで、解除爪は印刷台から造形される。
   カバーは積層0.1mmを目安にし、本体の背面上レールの橋渡し等をスライサーで確認する。
3. 電子部品を載せる前に、ねじを下穴へ垂直にゆっくりねじ込み、PLAにねじ山を作る。
   上カバー用はM2×6mm超極低頭、内部固定用はM2×5mmなべねじ。
   穴底まで締め込まず、部品が着座したら止める。通常のなべねじを上カバーに使うと頭が突出する。
4. 電池を抜き、部品表の配線案に従って部品へ先にはんだ付けする。
   接合部、ホルダー端子、未使用線を熱収縮チューブ等で絶縁する。PLA上ではんだ付けしない。
   モジュール下面の接合部が1.6mmの逃げに収まることを確認する。
5. ホルダーの電池を入れる面を背面へ向け、底面端子を縦板の穴へ通す。
   ホルダーを2本、スイッチ・PTC・ダイオードを各1本の結束バンドでトレーへ固定する。
   ホルダーのバンドは両端寄りで、参照電池の円筒にはかからない位置。電池との軸方向隙間は各1.5mm。
   バンドの頭はホルダーの背板の内側等へ置く。`…TieHeads` の収納範囲を参照し、配線と干渉しないことを確認する。
6. モジュールを枠へ載せ、別体押さえをM2×5mmねじ2本で留める。
   絶縁した配線を縦板の裏とトレー下面の溝・床側空間へ収める。
   電池交換口と電池の移動範囲に線を通さない。部品上面を押し潰さず、必要なら薄い絶縁クッションを使う。
7. トレーを本体へ載せ、M2×5mmねじ2本をPLA固定座へ直接ねじ込む。
   穴底の公称余裕は0.2mm。着座と底面への突出がないことを現物で確認する。
8. 固定USB-Cケーブルを出口へ通し、外皮を台座へ結束バンド固定する。
   引張り力がはんだ接合へ伝わらないこと、線や頭が蓋に当たらないことを確認する。
9. 導通・短絡・極性を確認し、保護部品込みで5V出力を評価する。
   内蓋を載せ、磁石の極性を合わせ、上カバーとM2×6mm超極低頭ねじ4本で共締めする。
10. スライドふたを背面レールの左端から右へ差し込み、解除爪のフックが固定爪を越えて閉位置を保持することを確認する。
    印刷品で電池交換、吸着、滑り、打鍵時の安定性と実機給電を評価する。

## 電池交換

1. 電源スイッチをOFFにする。
2. 背面ふたの左寄りにある解除爪を下へ押し、中央下側の引き手でふたを左へスライドさせて外す。
3. ホルダーのばね側へ電池を軽く寄せ、片側を起こして背面へ取り出す。新しい単4電池を極性を合わせて入れる。
4. ふたを右へ戻し、爪で閉位置を保持していることを確認してから電源を入れる。

磁石カバーと内蓋のねじ、トレー固定ねじ、ホルダーのバンドを外す必要はない構造。
ホルダーと配線は固定したまま。キーボードケースとのモデル上の干渉も確認したが、
実際に手が届くか、ホルダーの爪を越えて電池が外せるかは現物で評価する。
ふたを外す方向へ約60mmの作業スペースを確保する。難しければバーを磁石から外して交換する。
ふたは取り外し式で、外したときの紛失防止機構は設けていない。

## FreeCADでの確認・変更

`RightHousing`、`RightTray`、`RightModuleCage`、`RightLid`、`RightCover`、`RightBatteryDoor` が印刷部品。
左用は `Left…`。初期表示は右バーの外装・背面ふた・固定ケーブル。
内部を見るときは蓋とカバーを隠してトレー・押さえ・参照部品を表示する。
`…References` に購入部品の収納範囲、ねじ芯・頭、バンド、ケーブル、ケースと端子位置がある。
`…BatteryDoorOpen` と `…BatteryPullOut` は電池交換状態。閉じたふたと電池を隠して表示する。
`…BatteryExchangeSweep` は電池を取り出す経路の収納範囲。
`…Exploded` は分解状態のコピーで通常は非表示。組み立て形状を隠してから表示する。

形状は[生成スクリプト](generate-battery-tenting-bar.py)の定数からブーリアン演算で作成している。
FreeCADの寸法プロパティは記録用で、スケッチ／Padの履歴は持たない。
寸法を変える場合はスクリプトを変更して再生成する。生成物は上書きされる。

FreeCADのPythonコンソールから実行する例：

```python
from pathlib import Path
script = Path('/Users/beryu/ghq/github.com/beryu/torabo-tsuki-om/3d-models/FreeCAD/generate-battery-tenting-bar.py')
exec(compile(script.read_text(), str(script), 'exec'), {'__name__': '__main__', '__file__': str(script)})
```

環境変数 `KB1_CASE_FILE` で参照ケース、`TENTING_HOLDER_HEIGHT_MM`（既定15）でホルダー高さ、
`TENTING_CABLE_DIAMETER_MM`（既定3）でケーブル径を指定できる。
ホルダーの蓋余裕が0.5mm未満、またはモデルに干渉があれば生成を止める。
プレビューは `render-battery-tenting-bar.py` で実際のCADの三角形データから描画する。

## 検証と未確認事項

FreeCAD 1.1.0で左右12点の印刷部品が有効な単一ソリッドであること、
試し刷り2点を含め14点のSTLが閉じたメッシュで印刷台Z=0へ配置されることを確認した。
保存したFCStdとSTLも読み直した。検証記録は `validation.json` と `saved-files-validation.json`。

部品収納範囲、トレー、押さえ、ねじ芯・頭、固定バンド、ケーブルと外装の干渉、
底ケース・上ケースとの干渉を確認した。
解除後のふたをスライドさせる全経路と、電池を背面へ抜く全経路、Ø10mmの指先接近範囲も確認した。
閉じた爪はスライドを止める形状だが、解除形状は局所の逃げを移動した概略範囲で、弾性解析ではない。磁石の閉じた樹脂窓と上方への抜け止めも検証した。
参照ケースと生成スクリプトのSHA-256を記録している。
ねじの芯はØ1.5mmの参照円筒で、挿入経路と穴底を確認するための形状。
M2ねじの山がPLAへ食い込む部分はモデル化していない。ねじ頭は超極低頭Ø4.2×高さ0.5mm、
内部なべ頭Ø3.8×高さ1.6mmの収納範囲で確認した。

購入部品は一部の寸法が未実測で、ホルダーは電池込みの長方体、プラグは概略形状。
全配線・はんだ・ねじ・結束バンドの留め具を精密モデル化してはいない。
留め具は収納範囲の箱で、実際の形状・必要な結束バンド長さを確認する。
PLAは固定・絶縁空間を作る部材で、配線の被覆や接合部の絶縁を省けるものではない。
実物の組み立て、公差、PLAねじ山および解除爪の保持力・繰り返し着脱寿命、発熱、磁力、
電池交換、ケーブル曲げ、キーボードの給電動作は未評価。
このモデルはその評価に使う試作設計であり、実機動作を保証する完成品ではない。
