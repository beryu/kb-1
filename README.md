# kb-1

kb-1は、19mmトラックボールを搭載した左右分割キーボードです。

コンパクトな17mmピッチのカラムスタッカード配列を採用し、左右合わせて48キーを搭載しています。
トラックボールの高さを低く抑えることで、キーを打つときや持ち運びの邪魔になりにくくしています。
コントローラーにはSeeed Studio XIAO nRF52840 Plusを採用しています。XIAOは右側だけに搭載し、左右間はSamtec FTSHヘッダとFFSD-06-D-10.00-01-Nケーブルで接続します。PCとはBluetoothで通信しますが、動作中は右側USB-Cから常に給電する必要があります。

## 特徴

* 17mmピッチのカラムスタッカード配列
  * 左26キー、右22キーの48キー構成です。
* USB-C給電・Bluetooth接続
  * PCとの通信にはBluetoothを使用します。
  * 使用中は右側XIAOへモバイルバッテリーまたはUSB電源から常に給電する必要があります。
  * 電源スイッチはなく、USB-Cケーブルの接続／取り外しで電源を操作します。
  * 左右間は、Samtec FFSD-06-D-10.00-01-Nケーブルで接続します。
* Seeed Studio XIAO nRF52840 Plusを採用
  * XIAOは右側だけに搭載し、左側はスイッチとダイオードのみの受動基板です。
* トラックボールの設置位置が調整可能
  * トラックボールを取り付ける位置を調整して、自分にとって一番操作しやすい位置に設置できます。ボールの高さを抑えたことでキーを打つときの邪魔になりにくなっています。
* ZMK対応
  * [kb-1専用ファームウェア](https://github.com/beryu/zmk-keyboard-kb-1)を公開しています。
  * keymap-editorやZMK Studioを使用して簡単にキーマップが変更できます。

## 使用上の注意

* 異臭や煙が出たときは、ただちにUSB-C電源を外して使用を中止してください。
* 左右を接続するFFSDケーブルは、USB-C電源を外した状態で抜き差ししてください。
* USB-C電源とケーブルは、破損や発熱のない適合品を使用してください。
